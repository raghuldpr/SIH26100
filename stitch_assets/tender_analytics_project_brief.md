# Project Brief: Tender Analytics Dashboard (Quixotic)

## 1. Project Overview
**Quixotic Procurement** is a high-fidelity tender analytics platform designed to help procurement teams track, analyze, and manage tender compliance and verification workflows. The system centralizes complex data into an actionable dashboard, reducing the time spent on manual document review and risk assessment.

## 2. Target Audience
- **Procurement Managers**: Overseeing multiple active tenders and ensuring deadlines are met.
- **Compliance Officers**: Monitoring verification status and addressing critical documentation issues.
- **Data Analysts**: Tracking compliance trends and performance scores across the organization.

## 3. Design System & Brand Identity
- **Product Name**: Quixotic
- **Visual Style**: Modern, clean, and data-centric. Uses a professional "Forest Green" primary palette (`#125d44`) contrasted with soft surface blues for depth and hierarchy.
- **Typography**: Hanken Grotesk (Clean, geometric sans-serif for high readability).
- **Key UI Elements**: Rounded corners (8px), elevated cards, and subtle status-based color coding (Green for verified, Red for issues).

## 4. Current Architecture (Desktop)
### Navigation
- **Top Navigation Bar**: Global controls including Search, Notifications, and Profile management.
- **Side Navigation Bar**: View-level navigation (Overview, Wallet, Documents, History, Analytics) and primary CTA ("Analyze New Tender").

### Key Dashboard Components
- **Metrics Bar**: High-level KPIs (Active Tenders, Avg Compliance Score, Missing Documents, Critical Issues).
- **Compliance Analytics**: Monthly/Annual bar chart tracking organizational compliance performance.
- **Verification Status**: Radial chart showing the percentage of verified vs. pending items.
- **Recent Tenders Table**: Detailed line-item view of active procurement projects with due dates, scores, and status badges.

## 5. Technical Requirements
- **Responsive Design**: Desktop-first architecture with upcoming mobile-optimized views.
- **Component Library**: Standardized navigation and data display components for consistency across the suite.
- **Dynamic Data**: Support for real-time status updates and interactive chart filtering (Monthly vs. Annually).

## 6. Next Steps & Future Scope
- **Mobile Version**: Design a portrait-mode adaptation for on-the-go monitoring.
- **Deep-Dive Reports**: Detailed screens for individual tender analysis.
- **Document Management**: A centralized repository for handling "Missing Documents" flagged in the dashboard.
